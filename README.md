# Neon 11
a Windhawk theme with blur-glass & neon styling that reflects almost everything inside taskbar, custom app icons, more readable tray, battery and control center for Windows 11 Taskbar Styler mod by Windhawk https://windhawk.net/mods/windows-11-taskbar-styler 

Full Taskbar version:
![image alt](https://raw.githubusercontent.com/bydevara/Neon-11/refs/heads/main/Screenshots/Screenshot%20(2467)asd.png)


to make your taskbar exactly like the image above you better installed:
1. SF Pro font by Apple at https://developer.apple.com/fonts/
2. Taskbar Fluent Media Player by Salyts & gr0ud
(Windhawk mod👇)
3. Always show all taskbar tray icons by m417z
4. Taskbar tray icon spacing and grid by m417z
5. Start button always on the left by m417z
6. Taskbar height and icon size by m417z
